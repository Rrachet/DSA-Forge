# Contributing

DSA Forge values correctness, clarity, and useful explanations over solution volume.

## Guidelines

- Use Java 21.
- Keep one primary algorithm/data structure per class.
- Document time and space complexity.
- Add JUnit tests for normal cases and edge cases.
- Prefer descriptive names over clever abbreviations.
- Do not submit copied solutions without explanation or attribution.
- Keep benchmarks separate from correctness tests.

## Pull requests

Explain the problem, approach, complexity, and test coverage in the PR description.
