# Algorithm Catalogue

| Algorithm | Pattern | Time | Extra Space |
|---|---|---:|---:|
| Binary Search | Divide & conquer | O(log n) | O(1) |
| Two Sum | Hashing | O(n) average | O(n) |
| Valid Palindrome | Two pointers | O(n) | O(1) |
| Reverse Linked List | Pointer manipulation | O(n) | O(1) |
| Valid Parentheses | Stack | O(n) | O(n) |
| Circular Queue | Circular buffer | O(1) | O(n) |
| Frequency Counter | Hashing | O(n) average | O(k) |
| Binary Search Tree | Tree | O(log n) average | O(h) |
| Kth Largest | Heap / Top-K | O(n log k) | O(k) |
| BFS | Graph traversal | O(V + E) | O(V) |
| DFS | Graph traversal | O(V + E) | O(V) |
| Merge Sort | Divide & conquer | O(n log n) | O(n) |
| Quick Sort | Divide & conquer | O(n log n) average | O(log n) average |
| Factorial | Recursion | O(n) | O(n) stack |
| Subsets | Backtracking | O(n·2ⁿ) | O(n·2ⁿ) output |
| Activity Selection | Greedy | O(n log n) | O(n) |
| 0/1 Knapsack | Dynamic programming | O(nC) | O(C) |
